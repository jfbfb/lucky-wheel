# 背景音乐

请把 **好运来** 音频文件放到本目录，并命名为：

```
haoyunlai.mp3
```

## 要求

- 格式：`MP3`（推荐）或 `M4A`（需同时改 `index.html` 里的 `BGM_PATH`）
- 文件名必须一致：`haoyunlai.mp3`
- 建议码率 128–192 kbps，体积控制在 5MB 以内，加载更快

## 放好后

1. 本地双击 `index.html` 或 `npx serve .` 试听
2. 确认能循环播放后，在项目根目录运行 `.\update.ps1` 推送到 GitHub

## 在线地址

https://jfbfb.github.io/lucky-wheel/

推送后约 1–2 分钟，访客打开页面即可听到背景音乐（浏览器可能需先点击页面一次才允许自动播放）。
